# I miei soldi

Web app personale (PWA) per saldo, spese, contanti e previsione del mese prossimo.
Funziona offline: i dati restano solo sul telefono (localStorage). Backup e ripristino da Conti.

Pubblicata con GitHub Pages: branch `main`, cartella `/ (root)`.
Per aggiornare: modifica i file e aumenta `VERSIONE` in `sw.js`.
